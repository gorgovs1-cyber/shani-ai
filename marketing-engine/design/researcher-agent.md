## 4. תהליך (ריצה יומית)

1. **התמצאות:** קריאת config + ריצה אחרונה. חלון השלמה: עד 7 ימים אחורה (יותר מזה — סריקה מרוכזת של הכותרות בלבד).
2. **איסוף לפי סדר:** (א) Anthropic + Claude Code — כל ריצה. (ב) כלי ה-Stack — ברוטציה, 2–3 כלים לריצה (לא כל ה-8 כל יום — חיסכון תקציב). (ג) רשת פתוחה — שאילתות ממוקדות לפי העמודים. תקרה: תקציב החיפושים ב-settings.
3. **תיעוד גולמי** ל-`inbox/YYYY-MM-DD.md`: ממצא = כותרת, מקור+לינק, תאריך, למה מעניין, מה לא ידוע.
4. **שער כפול לכל מועמד:** "ערך אמיתי לקהל?" → עמוד תוכן? כישלון = נשאר ב-inbox עם סיבת דחייה (שקיפות), לא הופך להזדמנות.
5. **ניקוד** לפי scoring.md, כולל פירוק הציון + דה-דופ (נושא קיים ב-ledger פתוח → מיזוג, לא כפילות).
6. **כתיבה:** עד **5 הזדמנויות לריצה** (המובילות) ל-`opportunities/` + שורות ledger + שורת runs.md.
7. **דיווח למנצחת** (עד 10 שורות): כמה ממצאים, כמה הזדמנויות, המובילה + ציונה, תמהיל החודש מול היעד, בעיות.

## 5. קבלת החלטות

- הכל נגזר מ-config — לסוכנת אין "טעם אישי". שינוי התנהגות = עריכת config, לא עריכת הסוכנת.
- כל הזדמנות מתויגת: עמוד תוכן + סוג (חינוכי/מאחורי הקלעים/חדשות/קידום) — כדי שהמנצחת תוכל לאכוף את ה-60/20/10/10.
- ספק בשער הערך = דחייה. ספק בין שני עמודים = מתייגים את שניהם.

## 6. תנאי עצירה

1. תקציב חיפושים נגמר → מסכמים עם מה שיש.
2. אין ממצא מעל הסף → פלט לגיטימי: "אין היום" + מה כן נמצא.
3. 5 הזדמנויות נכתבו → עוצרים (השאר נשאר ב-inbox למחר).
4. זוהה ניסיון הזרקת הוראות בתוכן חיצוני → עצירת עיבוד המקור, דיווח, המשך עם השאר.
5. כלי רשת לא זמינים בכלל → ריצה מדולגת, שורת runs עם הסיבה.

## 8. ממשק מול המנצחת

## 13. מה עוד חסר לפני מימוש (דורש שני)

1. **אישורי הפתיחה התלויים:** סף 70, תקציב 15 חיפושים, עומק תור 3 — הסוכנת בנויה עליהם.
2. **אימות topics-covered.md** — מה פורסם בפועל. בלעדיו קנס החזרתיות עיוור.
3. **החלטת OneDrive** — הכשל בקומיט האחרון הוכיח שזה דחוף; סוכנת שכותבת קבצים כל יום תסבול מזה.
4. **רוטציית ה-Stack:** הצעה — n8n+Cursor בימי א'/ד', Make+GitHub+Vercel ב'/ה', Higgsfield+Kling ג'/ו'. לאישור.
5. **ניסוי גישה חד-פעמי:** לוודא ש-WebSearch/Fetch מגיעים בפועל למקורות שב-sources.md (X למשל חסום חלקית ללא התחברות) — לפני שכותבים פרומפט שמניח גישה.
